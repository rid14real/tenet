# Roadmap

The order follows the market research: win the NDPC audit-return cycle for DPCOs first, add AI governance on the same records, then expand jurisdictions.

## Before the 2027 audit-return season (now – Feb 2027)

- Verify the rule pack against primary texts: GAID schedules and tier thresholds, filing fees, the request-response period, and the 2027 return deadline. Then move each rule's provenance to "primary".
- Build a user admin screen and invitations (the API exists).
- Export the filing pack as Word and PDF, in the layout DPCOs submit.
- Show DPCO-level dashboards across clients, with bulk deadline reminders by email.
- Add evidence attachments (file uploads) on records and attestations.
- Write the platform's own DPA, privacy notice and sub-processor list. Register the platform with the NDPC if that is required.
- Run a penetration test and set the baseline for ISO 27001 controls.

## 2027

- Data subject intake through a web form and WhatsApp, with identity verification steps.
- Templates for DPIAs, legitimate-interest assessments and transfer impact assessments, written in Nigerian practice language.
- An assistant that drafts notices and first DPIA drafts from the record. It cites its sources, needs sign-off, and never sends client personal data to a model without consent.
- Content packs for Ghana and Kenya. Then confirm, as a deliberate step, which rules have been checked against primary text.
- AI governance:
  - Evidence for CBN model validation.
  - An ISO 42001 Statement of Applicability generated from the register.
  - Discovery of unapproved AI tools from browser and identity-provider signals.
- ISO 27001 certification.

## 2028 onward

- Connectors for discovery: cloud storage, HR and core-banking exports. These run on the customer's side and send only metadata.
- A dedicated hosting cell in Lagos for banks and government. AWS Cape Town stays the shared default.
- Content packs for POPIA (through a partner), Egypt, Rwanda and Francophone West Africa.
- Packs for EU, UK and US regimes, aimed at multinationals with African operations.
- ISO 27701 and ISO 42001 certification for the platform itself.
