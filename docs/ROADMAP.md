# Roadmap

The order follows the market research. First, win the NDPC audit-return cycle for DPCOs and in-house teams. Next, add AI governance on the same records. Then expand jurisdictions, which the packs in v0.2 already allow.

## Done in v0.2

- Organisations run in one of two modes, in-house or advisory, and each is its own tenant.
- Jurisdiction packs for NG, ZA, KE, GH, EG, ZW, EU and UK. Fields, requirements, rights, breach tests and citations all follow the selected laws.
- Separate modules for the data map (activities, systems, flows), vendor risk, the four assessment types, incidents, requests and governance.
- A merged action plan, with tasks.

## Before the 2027 audit-return season (now – Feb 2027)

- Verify each pack against primary texts, then move each rule's provenance to "primary". Start with the GAID schedules and tier thresholds, the filing fees, the request-response periods, and the Kenya and Ghana registration rules.
- Export reports as Word and PDF, in the layout DPCOs submit.
- Evidence attachments (file uploads) on records, assessments and incidents.
- Email reminders for deadlines, request clocks and breach clocks.
- Groups for in-house organisations with subsidiaries: group-level policies inherited by entities.
- Write the platform's own DPA, privacy notice and sub-processor list. Register the platform with the NDPC if that is required.
- Penetration test, MFA, and the baseline for ISO 27001 controls.

## 2027

- Data subject intake through a web form and WhatsApp, with identity verification.
- An assistant that drafts notices and first assessment drafts from the record. It must cite its sources, require sign-off, and never send client personal data to a model without consent.
- AI governance:
  - Evidence for CBN model validation.
  - An ISO 42001 Statement of Applicability generated from the register.
  - Discovery of unapproved AI tools from browser and identity-provider signals.
- Packs for Rwanda, Uganda, Côte d'Ivoire and Senegal.
- ISO 27001 certification.

## 2028 onward

- Connectors for discovery: cloud storage, HR and core-banking exports. These run on the customer's side and send only metadata.
- A dedicated hosting cell in Lagos for banks and government. AWS Cape Town stays the shared default.
- Packs for US state laws, aimed at multinationals with African operations.
- ISO 27701 and ISO 42001 certification for the platform itself.
